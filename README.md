# NodeSeek 楼中楼

把 NodeSeek 分散在不同楼层、不同分页的回复整理成楼中楼，减少来回翻页和查找引用楼层。

[点击安装脚本](../../raw/main/nodeseek-nested-replies.user.js)

## 功能

- 自动识别 `@用户 #楼层` 回复关系，支持跨页回复链。
- 每个楼中楼默认显示 3 条回复，其余内容可展开或收起。
- 回复默认紧凑显示；点击“展开详情”可查看签名、点赞、引用和回复按钮。
- 头像打开 NodeSeek 原生个人卡片，用户名进入个人主页。
- 点击 `#楼层` 可定位普通楼层或楼中楼回复。
- 保留 HOT、置顶评论及其原有位置。
- 页面右上角提供楼中楼开关，关闭后恢复原始评论布局。
- 支持浅色、深色主题和移动端页面。

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)（篡改猴）。
2. 点击上方“安装脚本”。
3. 在 Tampermonkey 安装页面确认源码和权限，然后点击“安装”。
4. 打开或刷新任意 NodeSeek 帖子页面。

如果点击安装链接后只显示源码，请点击 GitHub 页面右上角的 **Raw**。

## 使用

- 安装后默认启用，不需要额外设置。
- 点击页面右上角的楼中楼按钮，可随时开启或关闭。
- 点击楼中楼回复右侧的“展开详情”，查看完整楼层和原生操作按钮。
- 跨页详情首次展开时需要加载来源页，可能会稍等片刻；同一分页只加载一次。

## 安全说明

- 脚本仅在 `https://www.nodeseek.com/post-*` 页面运行。
- 使用 `@grant none`，不申请 Tampermonkey 特权 API。
- 不读取 Cookie、密码、令牌、剪贴板或私信。
- 不自动点赞、回复、关注或执行其他账号操作。
- 跨页数据仅请求当前 NodeSeek 帖子，最多读取前 12 页。
- 点赞、回复、引用和个人卡片均调用 NodeSeek 原生功能。

完整安全边界见 [SECURITY.md](./SECURITY.md)。请只从本仓库安装脚本，不要安装来历不明的修改版。

## 常见问题

### 安装后没有效果

确认 Tampermonkey 和本脚本均已启用，然后刷新 NodeSeek 帖子页面。

### 跨页详情加载失败

先刷新页面重试。仍然失败时，请在 Issues 中提供帖子链接、页码、浏览器版本和 Tampermonkey 版本，不要提交账号或登录信息。
